# 名場面事件圖 · 生成 Prompt(貼 ChatGPT / DALL-E / Sora)

每張 = **STYLE BLOCK** + 該場面的 **SCENE**。英文出圖最好。檔名 = **event id**:
```
sips -s format jpeg -s formatOptions 82 --resampleWidth 1400 in.png --out <event-id>.jpg
```
缺圖不崩(banner 自動隱藏)。

---

## ⭐ STYLE BLOCK(每個 prompt 前都貼)

```
Epic cinematic Chinese historical key art, late Han dynasty / Three Kingdoms era (3rd-century
China). Photorealistic painterly matte-painting, ultra high resolution, highly detailed, sharp
focus. Dramatic cinematic lighting, atmospheric haze, volumetric god-rays. Muted heroic palette:
antique gold, earth brown, deep crimson, charcoal black, jade accents. Authentic Han armor,
lacquered plate, silk war banners, grey-tiled architecture. Dynamic storytelling composition,
shallow depth of field. 16:9 widescreen.
NEGATIVE: no text, no captions, no watermark, no signature, no modern elements,
no Japanese/Ming/Qing aesthetics, keep Han-era 3rd-century China.
```
